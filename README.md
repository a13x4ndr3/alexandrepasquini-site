# alexandrepasquini.online — React (Vite + TypeScript)

## Editing content
All text, numbers and links live in **`src/content.ts`**. Edit there, commit, and Vercel redeploys automatically.
- Photo / CV / book cover: put files in `public/assets/` and reference them as `/assets/<file>`.
- Testimonials section appears automatically once `testimonials` in `content.ts` has items.

## Run locally (optional)
npm install
npm run dev

## Vercel
Framework preset: **Vite** · Build command: `npm run build` · Output directory: `dist`
